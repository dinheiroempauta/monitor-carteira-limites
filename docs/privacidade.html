Política de Privacidade

Monitor de Carteira — ferramenta pessoal de acompanhamento de investimentos. Última atualização: 25/08/2026.

Monitor de Carteira é uma ferramenta de uso pessoal e individual — não é um produto distribuído a outros usuários, não tem cadastro, login público nem base de usuários. Ela existe para automatizar o acompanhamento da carteira de investimentos de uma única pessoa, seu criador e único usuário.

O que a ferramenta acessa

A ferramenta usa a API do Gmail, com permissão de somente leitura (escopo gmail.readonly), para:

  • Buscar, na própria caixa de entrada do usuário, e-mails de notas de negociação enviados pela corretora (remetente noreply@rico.com.vc).
  • Ler o conteúdo desses e-mails específicos e o PDF anexado, para extrair os dados de cada operação (ativo, quantidade, preço, data).

A ferramenta nunca envia, apaga ou modifica nenhum e-mail — o escopo usado não permite nenhuma dessas ações, só leitura.

O que é feito com os dados

Os únicos dados extraídos dos e-mails (ticker do ativo, quantidade, preço e data da operação) são gravados em um arquivo de texto (CSV) dentro do repositório de código do próprio usuário no GitHub, para alimentar os cálculos de alocação de carteira e os gráficos de performance da própria ferramenta.

Nenhum outro conteúdo do e-mail (remetente, assunto, corpo do texto, outros anexos) é armazenado, processado ou compartilhado. Nenhum dado é enviado a terceiros, serviços de analytics ou qualquer outro destino além do próprio repositório do usuário.

Compartilhamento com terceiros

Não há compartilhamento de dados com terceiros. Os dados usados por esta ferramenta transitam apenas entre a conta Gmail do próprio usuário, a execução automatizada (GitHub Actions) e o repositório do próprio usuário no GitHub.

Revogar o acesso

O acesso concedido a esta ferramenta pode ser revogado a qualquer momento em myaccount.google.com/permissions.

Contato

Por ser uma ferramenta de uso pessoal, dúvidas sobre esta política podem ser encaminhadas por meio das issues do repositório no GitHub.
